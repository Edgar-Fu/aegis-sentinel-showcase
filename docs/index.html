Run the actual backend

Windows

powershell -ExecutionPolicy Bypass -File .\scripts\verify.ps1

powershell -ExecutionPolicy Bypass -File .\scripts\run.ps1

macOS / Linux

./scripts/verify.sh

./scripts/run.sh

Then open http://localhost:8080. No Maven, database, API key, model download, or external service is required.
