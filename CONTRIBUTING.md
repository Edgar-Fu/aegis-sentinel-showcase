# Contributions

This repository is maintained as a curated recruiter-facing showcase of a privately developed system. Public issues that identify reproducible bugs in the showcase are welcome.

Pull requests are not accepted by default because accepting outside code can complicate ownership of the private and potentially commercial Aegis Sentinel codebase. A contribution may be considered only after a separate written contribution agreement is established.

Please do not submit proprietary code, confidential data, third-party sample media without clear redistribution rights, or changes that attempt to reconstruct intentionally omitted private components.
