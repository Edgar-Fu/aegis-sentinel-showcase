# Security policy

## Supported scope

Only the latest commit on the default branch of this public showcase is supported.

## Reporting

Please report a security issue privately through the contact options on [Edgar Fu's GitHub profile](https://github.com/Edgar-Fu). Do not include exploit details in a public issue before a reasonable opportunity to review the report.

## Important limitations

This repository is a local recruiter demonstration, not a production service:

- it has no authentication or authorization;
- it is not designed to be exposed directly to the public internet;
- it uses illustrative public governance thresholds;
- it does not include the private real-model adapter;
- it accepts local image uploads up to 10 MB;
- runtime evidence is stored on the local filesystem;
- it has not been certified for safety-critical or autonomous operation.

Run it only on a trusted development machine or inside an appropriately isolated environment.
