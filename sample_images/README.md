# Synthetic fixtures

These images were created specifically for the Aegis Sentinel Public Showcase and are copyright © 2026 Edgar Fu.

- `trusted_source_a.png` and `trusted_source_b.png` depict the same controlled warehouse state with small positional changes.
- `conflict_source_b.png` introduces a visible spill and blocked exit.
- `rejected_blur.png` is a strongly blurred derivative used to exercise the integrity gate.
- `MANIFEST.json` records the SHA-256 and dimensions of every fixture.

They are engineering fixtures, not independent sensor captures, model-accuracy benchmarks, or evidence of real-world detection performance.
